Start
URL einfügen → Laden → im Preview auf ein sichtbares Element klicken → Auslesen. Das Tool extrahiert nur öffentliche Inhalte aus dem geladenen DOM.
Export
Der Output kann direkt kopiert werden. Für 1:1-Nachbau ist der öffentliche DOM plus CSS der beste Ausgangspunkt; dynamische JS-Zustände werden nur sichtbar, wenn sie im geladenen Inhalt vorhanden sind.
